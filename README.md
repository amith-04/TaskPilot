# TaskPilot — My First Online Hackathon Project

TaskPilot is a task management website developed for my first online hackathon under the domain **AI for Everyday Life**.

### Initial Objective
The goal was to build an AI-powered to-do list that could:
1. Accept user tasks.
2. Process task details.
3. Analyze tasks using AI.

### Implementation
The project was deployed using **Vercel**, marking my first experience deploying a website.

However, the AI functionality was not implemented due to time constraints and limited experience integrating AI APIs. The result was a basic prototype without actual AI capabilities.

### Key Takeaways
- First experience deploying a website using Vercel.
- Exposure to hackathon development and time constraints.
- Identified gaps in AI API integration and implementation.

**Status:** Prototype deployed. AI integration not implemented.
